Manual Addition of Report Pages
1 | Right Click on the name (at the bottom) of the worksheet to be added and select Move or Copy
2 | Then select the workbook to move (or copy) from the drop down menu To book
3 | Next select the location from the list Before sheet
4 | Finally check the box Create a copy or not as required
Installing a Macro in Another Workbook
1 | Should you prefer to create the report first and then add the macros, then proceed as follows
2 | On the Excel menu lick Tools then Macro then Visual Basic Editor
From the Visual Basic menu select View Project Explorer you will see VBA Project (your workbook name)
and VBA Project (master_report_2003.xls)
3 | Click + opposite Modules for each to view the modules attached to each file; your workbook may or
may not already have modules. Note that you will need the macro password (from your supervisor)
to do this
The master_report_2003.xls project has five Modules ; 'Add_Pages', 'Auto_PDF_Print'
'Page_Setup_All_Pages' and 'Remove_Names' as described above
4 | Drag the required Module across to your workbook project and drop it into the Modules folder, if there is
one, otherwise into the Microsoft Excel Objects folder
5 | Return to master_report_2003.xls in Excel and right mouse button click on the appropriate button required
to activate the macro. Select Copy and then paste it into the front page worksheet of your workbook
(for the 'Page_Setup_All_Pages' macro this worksheet must be named 'Front' or the macro will not work)
6 | Right mouse button click on the newly pasted button and select Assign Macro, Macros in This Workbook
and double click the appropriate macro name
Report Page Defaults
The front page, back page and letter page defaults are as in this workbook
Standard report pages in the calculation workbooks have been set up as follows
Font Ariel (or Helvetica) - general font size = 9
Rows 1 to 9 have row height = 13
Rows 10 to 65 have height = 11.75
Header on line 8 (except for C36+ first composition page which is on line 6)
Header format is Ariel 11 Bold Underlined Vertical Alignment Centre
Two blank rows under each header can be used for sub-headers
Data tables start on line 11 (except C36+ first composition page - line 9)
Table headers are coloured light grey (as this line) and are not outlined
Table subheaders are Ariel 9 Bold on a light grey background
Footnotes format is Ariel 8 (as are fomulae on first composition page)
Graph Axes labels format is Ariel 8.5 Bold and scale numbers are 8.5 Regular
Manually created pages should adhere to the above
